# Bi-bi XLSX Editor Lite 🚀

Современный и быстрый редактор XLSX файлов, оптимизированный для мобильных устройств, с облачной синхронизацией через Neon Postgres.

## ✨ Основные возможности

- 📊 **Быстрый просмотр**: Моментальная загрузка больших Excel таблиц прямо в браузере.
- ☁️ **Облачное автосохранение**: Все ваши пометки (цвета ячеек, текстовые заметки) автоматически сохраняются в облаке.
- 📱 **Мобильная адаптация**: Специальная цифровая клавиатура для быстрого поиска и навигации на телефонах.
- 🔍 **Умный поиск**: Мгновенная фильтрация строк и навигация по результатам.
- 🔐 **Личные аккаунты**: Собственная авторизация (email + пароль) с хранением пользователей в Neon — ваши файлы доступны только вам.
- 📂 **Экспорт**: Сохранение отредактированного файла обратно в формат XLSX со всеми стилями и комментариями.

## 🛠 Технологии

- **React + Vite + TypeScript** — фронтенд
- **Vercel Serverless Functions** (`/api`) — бэкенд
- **Neon Postgres** (`@neondatabase/serverless`) — база данных
- **JWT + bcrypt** — авторизация
- **ExcelJS** (обработка файлов), **Bootstrap 5** (стилизация)

## 🏗 Архитектура

Neon — это база данных (Postgres), а не сервис авторизации. Подключаться к ней
напрямую из браузера нельзя (это раскрыло бы строку подключения с паролем), поэтому
между фронтендом и базой стоит серверный слой — Vercel Serverless Functions:

```
Браузер (React)  ──fetch /api/*──►  Serverless Functions (/api)  ──SQL──►  Neon Postgres
   JWT в localStorage                 DATABASE_URL только здесь
```

API-эндпоинты:

| Метод  | Путь                | Назначение                          |
|--------|---------------------|-------------------------------------|
| POST   | `/api/auth/signup`  | Регистрация, возвращает JWT         |
| POST   | `/api/auth/login`   | Вход, возвращает JWT                |
| GET    | `/api/auth/me`      | Текущий пользователь по токену      |
| GET    | `/api/files`        | Список файлов пользователя          |
| POST   | `/api/files`        | Создать/обновить файл (upsert)      |
| POST   | `/api/files/delete` | Удалить файл                        |

Таблицы в Neon: `bibi_users`, `bibi_files` (префикс `bibi_`, т.к. в базе живут и
другие проекты). Схема — в [`schema.sql`](./schema.sql).

## 🚀 Как запустить локально

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Настройте переменные окружения. Создайте `.env.local` на основе `.env.local.example`:
   ```env
   DATABASE_URL=postgresql://user:password@host.neon.tech/dbname?sslmode=require
   JWT_SECRET=случайная_длинная_строка
   ```
   Сгенерировать секрет: `node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"`

3. Примените схему БД (один раз):
   ```bash
   node scripts/apply-schema.mjs
   ```

4. Запустите проект через Vercel CLI (чтобы работали и фронт, и `/api`):
   ```bash
   npm i -g vercel
   vercel dev
   ```
   > `npm run dev` поднимает только фронтенд (Vite) без серверных функций —
   > авторизация и сохранение работать не будут. Для полноценного локального
   > запуска нужен `vercel dev`.

## ☁️ Деплой на Vercel

1. Импортируйте репозиторий в Vercel.
2. В **Settings → Environment Variables** добавьте `DATABASE_URL` и `JWT_SECRET`
   (те же значения, что в `.env.local`).
3. Деплой запустится автоматически. Vercel сам соберёт фронтенд (Vite) и
   функции из папки `/api`.
